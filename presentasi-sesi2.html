Sistem Berpikir Claude

ChatGPT (Fluency)

Input → langsung generate
jawaban → output

Dilatih untuk kefasihan bahasa — jawaban langsung cair.

Claude (Reasoning)

Input → [berpikir/menyusun
strategi] → baru jawab

Dilatih untuk reasoning eksplisit — mikir dulu: struktur, format, konteks.

Contoh: "Buat surat undangan rapat evaluasi"
ChatGPT: langsung mulai menulis surat
Claude: [mikir] — formal/semi-formal? perlu kop surat? siapa pengirimnya? → baru nulis dengan struktur tepat

Dampak Sistem Berpikir Claude untuk Tendik

Claude lebih cocok untuk tugas yang butuh presisi dan struktur:

TugasKenapa Claude Lebih Cocok
Surat resmiMikir format dulu, bukan asal nulis
SOPMikir alur logis sebelum nyusun langkah
LaporanMikir organisasi konten, bukan sekedar nempel data
NotulensiMikir mana keputusan, mana tindak lanjut

Tapi... kenapa ChatGPT lebih populer?

  • Pertama masuk pasar — brand awareness lebih besar
  • Gratisan cukup baik — GPT-3.5 gratis tanpa batas berarti
  • Multimodal lebih awal — image generation (DALL-E) built-in
  • Integrasi luas — Microsoft, plugin, API ecosystem
Claude = unggul secara teknis & reasoning, ChatGPT = unggul secara distribusi & ekosistem

Budaya Membuat Alat / Tools

"Kita Bukan Pemakai, tapi Pembuat"

Selama ini sebagai tendik kita memakai alat yang sudah jadi — Microsoft Word, Google Docs, aplikasi surat dari pusat. Sekarang kita bisa membuat alat sendiri.

Old Mindset

  • "Tunggu IT bikin aplikasi"
  • "Nggak bisa coding"
  • "Kerja manual berulang-ulang"
  • "Prosedurnya ribet"

New Mindset

  • "Saya bikin tools sendiri"
  • "Cuma perlu ngomong, AI yang bikin"
  • "Bikin tools, pakai berkali-kali"
  • "Tools yang menyederhanakan"
DuluSekarang
Buka Word → ketik notulensi manual → format sendiriBuka Canvas → isi catatan → tools otomatis merapikan
Cari template surat → copy paste → edit manualIsi form Canvas → surat langsung jadi

AI adalah Alat yang Dapat Membuat Tools

Kapak batu → Mesin uap → Komputer → AI
(tenaga)     (produksi)     (informasi)     (intelegensi)

Setiap era punya alat yang memperluas kemampuan manusia.

AI Adalah "Tool Maker"

AI bukan cuma alat yang menjawab pertanyaan. AI adalah alat untuk membuat alat.

Sebelum

  • Mau bikin tools? → Belajar coding 2 tahun
  • Mau bikin aplikasi? → Bayar programmer
  • Tools butuh waktu berbulan-bulan

Sekarang

  • Mau bikin tools? → Jelaskan ke AI dalam Bahasa Indonesia
  • Mau bikin tools? → Gratis, tanpa coding
  • Tools jadi dalam hitungan detik

Apa Itu Gemini Canvas?

Gemini Canvas adalah fitur di Gemini yang bisa membuat aplikasi web interaktif langsung dari perintah bahasa alami. Tidak perlu coding.

Anda: "Buatkan tools notulensi rapat..."
    ↓
Canvas: [Membuat kode di belakang layar]
    ↓
Anda: [Langsung bisa pakai tools-nya!]
    ↓
Anda: "Tambah kolom tindak lanjut..."
    ↓
Canvas: [Langsung diperbarui]

Yang Bisa Dibuat dengan Canvas

✅ SOPInput prosedur → SOP rapi
✅ LaporanData mentah → laporan utuh
✅ NotulensiCatatan kasar → notulensi profesional

✅ Form & TrackerInventaris, surat masuk/keluar

Kenapa Cocok untuk Tendik?

  • Tidak perlu coding — cukup Bahasa Indonesia
  • Gratis — tidak perlu langganan
  • Cepat — tools jadi dalam hitungan detik
  • Bisa direvisi — tinggal minta, langsung diubah
  • Bisa di-export — simpan sebagai file HTML, offline
  • Bisa dipakai ulang — tools yang sama untuk tugas berulang

Alur Workshop

  1. Instruktur demo — bikin tools di depan, peserta lihat
  2. Peserta praktik — buka Canvas, ketik prompt yang sama
  3. Revisi bersama — minta Canvas menambahkan fitur
  4. Latihan mandiri — setiap peserta menyempurnakan tools-nya
  5. Hasil — setiap peserta pulang dengan 4 tools siap pakai

Yang perlu disiapkan: Browser (Chrome/Edge/Firefox), Akun Google, Koneksi internet stabil.
