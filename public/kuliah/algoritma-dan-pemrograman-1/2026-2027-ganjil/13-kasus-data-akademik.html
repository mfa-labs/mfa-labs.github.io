Bagian 01

Kasusnya

Pekerjaan seorang dosen setiap akhir semester.

Misi

Rekap nilai satu kelas

Dari satu daftar nilai, kita ingin tahu rata-ratanya, nilai tertinggi dan terendahnya, berapa yang lulus, dan sebaran nilai hurufnya.

Keterbatasan yang disengaja

Nilai tidak disimpan — dibaca satu per satu lalu langsung diolah. Setiap pertanyaan dijawab sambil data mengalir.

Bagian 02

Membaca aliran data

Nilai mengalir seperti barang di ban berjalan.

Pada setiap nilai yang lewat

Tiga hal yang bisa dilakukan

01Menambahkannya ke akumulatorMisalnya ke total
02Membandingkannya dengan yang dipegangUntuk mencari tertinggi atau terendah
03Memeriksa syaratnya, lalu menambah pencacahMenghitung kejadian

Wadah yang dipegang selalu sedikit dan tetap jumlahnya.

Teknik baru

Tertinggi sementara

IF nilai > tertinggi THEN tertinggi ← nilai ENDIF

Cukup menyimpan yang terbesar sejauh ini. Kalau nilai baru lebih besar, ganti; kalau tidak, biarkan.

Nilai awal diisi apa?

Jebakan di titik awal

Diisi 0 (rapuh)

Aman untuk nilai ujian, tetapi salah bila seluruh data bertanda negatif.

Dari data nyata

Ambil nilai pertama sebagai titik awal — selalu berasal dari keadaan sebenarnya.

Putaran pertama

Ambil nilai pertama

IF i = 1 THEN tertinggi ← nilai terendah ← nilai ENDIF

Pada putaran pertama, kedua wadah langsung diisi nilai pertama. Setelah itu, nilai-nilainya saling dibandingkan.

Bagian 04

Pseudocode lengkap

Semuanya dalam satu kali pembacaan data.

Algoritmanya

Rekap nilai kelas

DEKLARASI n, i, nilai : integer total, tertinggi, terendah, lulus : integer cacah_A, cacah_B, cacah_C, cacah_D : integer rata_rata : real BEGIN READ n total ← 0 lulus ← 0 cacah_A ← 0 cacah_B ← 0 cacah_C ← 0 cacah_D ← 0 IF n > 0 THEN FOR i ← 1 TO n DO READ nilai total ← total + nilai IF i = 1 THEN tertinggi ← nilai terendah ← nilai ENDIF IF nilai > tertinggi THEN tertinggi ← nilai ENDIF IF nilai < terendah THEN terendah ← nilai ENDIF IF nilai ≥ 60 THEN lulus ← lulus + 1 ENDIF IF nilai ≥ 85 THEN cacah_A ← cacah_A + 1 ELSE IF nilai ≥ 70 THEN cacah_B ← cacah_B + 1 ELSE IF nilai ≥ 60 THEN cacah_C ← cacah_C + 1 ELSE cacah_D ← cacah_D + 1 ENDIF ENDFOR rata_rata ← total ÷ n WRITE rata_rata, tertinggi, terendah, lulus WRITE cacah_A, cacah_B, cacah_C, cacah_D ELSE WRITE "tidak ada data" ENDIF END

Perhatikan

Tiga hal penting

01Semua wadah disiapkan di luarDelapan variabel diberi nilai awal sebelum FOR dimulai
02Satu READ melayani banyak perhitunganNilai yang sama dipakai untuk total, tertinggi, terendah, dan pencacah
03Pemeriksaan n > 0 menjaga pembagianKelas kosong berujung pembagian dengan nol

Rata-rata 73, tertinggi 90, terendah 55, lulus 4 dari 5.

Memeriksa kebenaran

Jumlah pencacah harus sama dengan banyak data.

2 + 1 + 1 + 1 = 5, cocok dengan n. Dan banyak yang lulus (4) sama dengan jumlah pencacah A, B, dan C. Pemeriksaan semacam ini menangkap nilai yang luput atau terhitung dua kali.

Hindari

Kesalahan yang sering muncul

  • Memberi nilai awal tertinggi dengan angka yang salah
  • Menaruh akumulator di dalam pengulangan
  • Lupa pemeriksaan n > 0
  • Urutan cabang nilai huruf terbalik
  • Memakai > padahal ≥ — nilai 60 salah dianggap tidak lulus
  • Menghitung rata-rata sebelum pengulangan selesai
